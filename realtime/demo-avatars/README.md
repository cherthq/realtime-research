# Demo reference portraits

Ten reference images used by the Chert video-call demo. Each is a 640 × 480
RGB PNG (4:3). PNG metadata is removed; portrait pixels match the existing demo.

`manifest.json` maps each file to its avatar ID, display name, SHA-256 checksum,
and suggested ElevenLabs stock voice. Voice assignments are creative casting
choices, not recordings or clones of the pictured people.
